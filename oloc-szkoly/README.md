# OL/OC - planer lustracji szkol

Oddzielny modul aplikacji KP PSP Radomsko.

Otworz plik index.html poprzez GitHub Pages, a nastepnie zaimportuj plik JSON ze zgloszeniami otrzymany osobno. Interfejs wyswietla placowki, mape OpenStreetMap, harmonogramy 10:00-14:00, pola statusu i linki nawigacji.

Wersja publiczna zawiera tylko kod aplikacji, bez kontaktow. Dane z importu sa przechowywane lokalnie w przegladarce. Trasy przed wyjazdem wymagaja weryfikacji. Korzysta z Nominatim i opcjonalnie publicznego serwera OSRM.
